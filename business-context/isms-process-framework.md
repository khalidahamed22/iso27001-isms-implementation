## 1. Purpose

This document defines the key processes required to establish, implement, maintain and continually improve the Information Security Management System (ISMS).

## 2. ISMS Process Structure

The CloudLedger ISMS consists of the following interconnected processes:

| Process ID | Process | Responsible Role |
|---|---|---|
| ISMS-P01 | Organisational Context and Scope Management | Information Security Manager |
| ISMS-P02 | Information Security Risk Assessment | Risk Owner / Information Security Manager |
| ISMS-P03 | Risk Treatment and Control Management | Information Security Manager |
| ISMS-P04 | Information Security Policy Management | Executive Management |
| ISMS-P05 | Access Control Management | IT Manager |
| ISMS-P06 | Supplier Security Management | Procurement / Information Security |
| ISMS-P07 | Incident Management | Security Team |
| ISMS-P08 | Business Continuity and Backup Management | IT Manager |
| ISMS-P09 | Security Awareness and Training | HR / Information Security |
| ISMS-P10 | Internal Audit | Independent Internal Auditor |
| ISMS-P11 | Management Review | Executive Management |
| ISMS-P12 | Corrective Action and Continual Improvement | Process Owners |

## 3. Process Interactions

The ISMS processes operate together as follows:

1. Organisational context and interested parties determine ISMS requirements.
2. The ISMS scope defines the boundaries of the management system.
3. Risk assessment identifies information security risks.
4. Risk treatment determines the controls and actions required.
5. Policies and procedures establish requirements for implementing controls.
6. Operational teams implement and maintain security controls.
7. Monitoring and evidence collection evaluate control performance.
8. Internal audits assess conformity and identify weaknesses.
9. Management reviews evaluate ISMS performance and strategic suitability.
10. Corrective actions address identified nonconformities and support continual improvement.

## 4. Process Monitoring

Each process owner must monitor the performance of their assigned processes.

Illustrative performance indicators include:

| Process | Performance Indicator |
|---|---|
| Access Management | Percentage of access reviews completed |
| Incident Management | Incident response and closure times |
| Backup Management | Successful backup and recovery test rates |
| Security Awareness | Employee training completion rate |
| Supplier Management | Percentage of critical suppliers reviewed |
| Risk Management | Percentage of risk treatment actions completed |
| Internal Audit | Percentage of audit findings closed by target date |

Targets must be established and approved by management.

## 5. Roles and Responsibilities

**Executive Management**
- Provide leadership and resources.
- Approve information security policies and objectives.
- Review ISMS performance.

**Information Security Manager**
- Coordinate ISMS implementation.
- Maintain risk and compliance documentation.
- Monitor information security performance.
- Report significant issues to management.

**IT Manager**
- Manage infrastructure security.
- Implement technical security controls.
- Maintain backup and recovery processes.

**Process Owners**
- Implement assigned security requirements.
- Maintain operational records.
- Report risks and control failures.

**Employees**
- Follow applicable security policies.
- Protect organisational information.
- Report suspected security incidents.

## 6. Continual Improvement

CloudLedger will continually improve its ISMS through:

- Periodic risk assessments.
- Security monitoring and performance evaluation.
- Internal audits.
- Management reviews.
- Corrective actions.
- Changes in technology, business operations and legal requirements.
